Vice City Cover Maker: a web app that turns your own photos into GTA-style multi-panel cover art. Upload up to three photos (or use the two free sample photos), pick a layout (hero + 2, 3-column grid, or full-bleed + strip), drag to pan and zoom each panel, choose a Vice City sunset or neon colour grade, edit the big bold title and subtitle, and export a PNG at 1080 x 1080, 1080 x 1350 or 1920 x 1080. Static files only, works offline in desktop Chrome, no network requests, no Rockstar logo, artwork or fonts — system fonts only.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
